# Betvora — Client (Frontend)

Professional casino-style gaming website — front-end demo with play money (session-only balances, no real money).

- Single self-contained `index.html` (all images embedded, no external assets)
- 32 playable games, wallet with demo deposit/withdraw, promotions, VIP club, leaderboard
- Deploy: GitHub Pages (Settings → Pages → Deploy from branch → `main` → `/(root)`)

Live: https://niczzxo.github.io/Betvora-client/
